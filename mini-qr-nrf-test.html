SmRF Mini — nRF-generated QR code

This page receives a QR matrix produced by the nRF54L15 firmware over USB serial and draws the exact black/white module pattern. Chrome does not encode the QR code. The phone then opens SmRF's overlaid Health Report.

DEMONSTRATION ONLY — the first firmware QR contains three SYNTHETIC days (Nov 6–8, 2026). It does not contain actual radon measurements or measured fan RPM. Fan hardware output remains disabled.

1 · Connect to Nordic serial console

Use Windows Chrome on this HTTPS page. Close the VS Code serial monitor first. Select the board's COM port (often COM3), then press RESET on the nRF DK so it transmits a fresh QR block.
