Closed-loop mitigation

Measure. Adjust. Verify. Repeat.

A complete local control loop—not merely an always-on fan.

1

Measure radon

A separate compatible CRM measures indoor radon and provides the feedback used by SmRF.

→

Compare with target

Verify the result

Purpose-built for fan control

Closed-loop radon mitigation using a separate monitor.

SmRF is designed to work with an established, compatible continuous radon monitor rather than incorporate a new radon sensor. That lets us focus development on dependable control, EC fan integration, and a practical path to market.

⌁

Independent CRM

Radon readings come from a separate compatible monitor, allowing SmRF to focus on turning measurement data into fan-control decisions.

◉

Variable-speed EC fan

SmRF Mini regulates fan output instead of leaving the fan at one fixed operating point.

▣

Local display

See current radon, 30-day average, fan speed, fan utilization, target, and operating status.

✓

Local autonomous control

The entire measurement and control process operates inside the home without internet service.

Measured in real homes

Built from field evidence—not theory alone.

Existing SmRF prototypes have generated the operating data needed to develop and validate the variable-speed control algorithms that SmRF Mini will use.

  • Radon response measured against commanded fan output
  • Target-based stepped speed changes tested in occupied homes
  • Daily, 7-day, and 30-day performance tracked over time

One control platform, a clear product path

From autonomous control to connected fleet visibility.

SmRF Mini focuses on local variable-speed fan control using an independent CRM. SmRF WiFi adds connected reporting and diagnostics while keeping fan control local. SmRF Viewer provides the optional remote monitoring layer. Neither controller incorporates its own radon sensor.

SmRF Mini→SmRF WiFi→SmRF Viewer
Focused first product

SmRF Mini

An autonomous local fan controller designed to use readings from a separate compatible CRM, with target selection, automatic 0–10 V fan control, and local operating status.

  • Separate CRM feedback
  • Local target-based control
  • Direct 0–10 V EC fan command
Connected evolution

SmRF WiFi

The connected SmRF platform uses a separate compatible CRM for radon feedback and combines local variable-speed fan control with WiFi reporting, remote diagnostics, software support, and installation visibility.

  • Control remains local
  • Remote reporting and diagnostics
  • Foundation for connected services
Remote monitoring layer

SmRF Viewer

The Viewer turns connected installations into a remotely visible fleet with performance history, operating status, attention rules, reports, and service information.

  • Installation and fleet status
  • Radon and fan history
  • Remote verification and support
