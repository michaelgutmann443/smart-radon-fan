SmRF Mini · Installer resources

Firmware updates, made simple.

SmRF Mini is being designed for wireless firmware updates using an iPhone and Nordic Semiconductor's nRF Connect Device Manager. No laptop or developer tools should be needed for a field update.

Production firmware downloads are not available yet.

SmRF Mini is undergoing bench validation. Development-signed test packages are not approved for field installation. This page will provide approved release packages and version-specific instructions when they are ready.

Bench-test firmware downloads

DEVELOPMENT USE ONLY · Not approved for active radon mitigation installations.

Previously published package: V0.32.5 bench ZIP. This is an older test build; do not use it to downgrade a V0.32.6 Mini.

On your iPhone, tap the download link, save the ZIP in Files (do not unzip), and select that file in nRF Connect Device Manager. Keep Erase Application Settings off. Only update a disconnected bench controller.

What you'll need

An iPhone with Bluetooth enabled, a properly powered SmRF Mini, and the free Nordic device-management app.

Get nRF Connect Device Manager for iPhone

An official SmRF smartphone app is not required for the initial update workflow.

How pairing works

When the phone requests authenticated Bluetooth pairing, Mini displays a six-digit passkey on its LCD. Enter that code on the iPhone.

Non-bondable pairing and the connection after a firmware restart are still being validated. A second pairing request may be necessary during an update.

Planned iPhone update procedure

These are the intended steps once an approved production release is published. Exact app selections and confirmation steps will be finalized after field validation.

  1. Download the approved firmware. Open this page in Safari and save the release ZIP into the iPhone's Files app. Do not unzip it.
  2. Connect to SmRF Mini. Open nRF Connect Device Manager, select SmRF-Mini, and enter the six-digit code displayed on Mini's LCD if requested.
  3. Select the update package. In the app's Image screen, select the downloaded ZIP. Keep Erase Application Settings switched off unless the official release instructions explicitly require otherwise.
  4. Install and verify. Follow the release-specific upgrade mode. Allow Mini to reboot and reconnect; complete confirmation if prompted. Verify the new firmware is shown as Active and Confirmed.

Release availability

Development validation in progress

There is currently no approved SmRF Mini production firmware package to download. A future release listing will show the firmware version, release date, file, and instructions.

Bench firmware may use development signing keys and is not intended for field deployment. Do not interrupt a firmware update or power-cycle a device running an unconfirmed test image without following the recovery instructions.
