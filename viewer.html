Viewer is the optional connected layer for SmRF VS-WiFi

The radon-control loop remains local. When remote visibility is useful, a VS-WiFi installation can report to the SmRF Viewer for one organized operational view of the installed base.

The Viewer brings together the measured radon result and commanded mitigation: current readings, averages, variable fan speed, status, decision reason, report timing, logs, charts, and alerts.

Connected when useful. Local where it matters.

Viewer is not part of the control loop. SmRF VS-WiFi continues controlling the fan locally if cloud connectivity is unavailable. Installations that do not need permanent WiFi can instead use SmRF VS-BLE.
