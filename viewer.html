Claiming a SmRF

The Claim Code proves that the installer has access to the physical SmRF or its local Managed Setup page.

1

Open Managed Setup

At the SmRF site—or through authorized remote access—open the device’s Managed Setup page and locate its Claim Code.

2

Select Add SmRF

Sign in to the Viewer, choose Add SmRF, and enter the Claim Code exactly as shown.

3

Confirm the fleet card

The claimed system appears in the organization’s fleet and can be opened for detailed review.

Fleet and device views

The fleet dashboard supports fast review; the device page provides the trend detail behind each installation.

Connected when useful. Local where it matters.
